# Domain Glossary — SA4E-106

These entries should be ingested into KB when database is available.

## Terms

| Term | Definition | Avoid |
|------|-----------|-------|
| Code Enrichment | The async process of adding LLM-generated metadata (summary, pseudo code, semantic tags) to source code symbols after tree-sitter indexing | annotation, decoration, labeling |
| CODE_ENRICHMENT | New TaskType enum value for the pending_tasks queue that handles symbol enrichment processing | code_analysis, code_tagging |
| Symbol Summary | A 1-2 sentence English description of a symbol's purpose and responsibility, generated by LLM | description, comment, doc |
| Pseudo Code | Structured numbered-step logic representation of a function body, abstracting away implementation details | pseudocode, algorithm, flowchart |
| Enhanced Pseudo Code | LLM-augmented version of PegaLogicNormalizer output that adds natural language explanations and business intent | improved pseudo, enriched pseudo |
| Semantic Tags | Domain-specific lowercase labels (3-8 per symbol) extracted by LLM that describe a symbol's purpose, domain, and patterns | keywords, categories, labels |
| Symbol Enrichments | Database table/storage that persists all enrichment data (summary, pseudo code, tags) for each code symbol | enrichment_data, symbol_metadata |
| Enrichment Task | A pending_tasks queue entry of type CODE_ENRICHMENT targeting a specific symbol_id for LLM processing | enrichment job, enrichment request |
